# SA2DX Chao World

**Version 0.3.1 — by SiK GambleR**

Adds three SADX-style Chao Gardens to the Sonic Adventure 2 (Steam, 2012) Chao World lobby:
**Station Square**, **Mystic Ruins** and **Egg Carrier**. A new corridor on the west side of
the lobby has a gate for each garden (brick = Station Square, stone = Mystic Ruins,
metal = Egg Carrier). Walk into a gate to enter that garden, and use the door inside to return.

## Install

1. Install [SA Mod Manager](https://github.com/X-Hax/SA-Mod-Manager).
2. Copy the `SA2DX Chao World` folder into the game's `mods` folder.
3. Enable **SA2DX Chao World** in the mod manager and start the game.

## Notes

- The Neutral, Hero and Dark gardens are unchanged.
- Garden geometry and textures are converted from SADX data at build time and shipped as
  generated assets; this repository does not include game files.
- The two `Enable*.flag` files in the mod folder switch the gardens on. Do not delete them, or only the Neutral garden loads.
